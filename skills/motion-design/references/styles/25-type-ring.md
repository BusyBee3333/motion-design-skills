# 25 Type Ring
**Feeling:** editorial, confident, rhythmic, crafted
**Good for:** title cards, editorial "how it works" openers, end cards with a URL, any line that should read as a cycle
**Avoid when:** the ring copy is long (it must fit the circumference) or the format is very wide and short
**Mechanism:** concentric hairline SVG rings drawn on with stroke-dasharray, a 72-tick bezel, and two glyph rings built per character (display 62 px outer, mono 22 px inner; glyph spacing measured with canvas so each ring closes exactly). Glyphs pop in around the circle with back-out (k=2.2) and wipe out before the loop. Rings rotate in opposite directions on a speed profile u + a·sin(2π(u−φ))/2π: fast spin-in, almost still in the reading hold, a whole number of repeats per loop so it is seamless. A pulsing foil ∞ is the focal mark at the loop point; the showcase case pops in over it (~12% overshoot), sways ±6° in Y, then anticipates +4% and pops out. The headline types in with letter-spacing .14→.01em.
**Timing:** 6 s loop. Rings draw 0.05–1.2 s, glyph wipe 0.15–1.0 s, case 0.9–1.4 s, headline 1.35–2.2 s, hold to 4.7 s, exits 4.7–5.6 s, ∞ returns 5.25–5.7 s. Poster 3.2 s.
**Swap points:** COPY `outerRing` (~40 chars incl. " · " separators, repeated twice), `ringAccent` (substring of outerRing in --accent), `innerRing` (~50 chars), `headA` / `headB` (≤ 12 chars each, headB in foil), `brand`, `figure`, `cornerRight`, `footLeft`, `footRight`, `caseEyebrow`, `caseTitle`, `caseNumber`, `cardName`. Art: `<div class="art" style="--art:url(your-image.png)">` on the case card. Roles: --text hairlines and glyphs, --accent ticks/dots/accent words, --primary-hi separators, --primary halo.
**Adapting:** swap the case for a logo or product image in `#slabwrap`. For 16:9 keep the ring centred and move headline and URL row to the sides. If the ring text gets longer, drop the font size or set reps to 1 rather than squeezing the gap.
