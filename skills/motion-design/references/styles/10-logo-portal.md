# 10 Logo Portal
**Feeling:** hypnotic, playful, premium, endless
**Good for:** logo opens and closes, "one token opens a whole world" stories, any brand mark → product scene transition
**Avoid when:** the viewer must read body copy; text is only readable during the short holds
**Mechanism:** an infinite Droste zoom. Levels nest: hub scene > pass > hub scene > pass ... (7 levels). The pass's punched hole is a circular window that holds the next hub scene, sized so the frame corners touch the foil ring (h = R / (half-diagonal·1.12)). The hub holds a small pass (m = .30) whose hole holds the next hub. The camera is a similarity transform: zoom about the hole centre (log 1/h), then about the fixed point of the mini-pass map (log 1/m). At t = DUR it lands exactly one pass level deeper, so the loop is mathematically seamless. Depth of field: a level's blur is driven by its on-screen scale, and text on an out-of-focus hub fades out.
**Timing:** DUR 5 s; pass hold 4.3→0.75 (wraps, 4.5%/s drift); dive through hole 0.75→1.95 (bezier .55,0,.12,1); hub read 1.95→3.05; dive into the hub's pass 3.05→4.3. POSTER 2.45.
**Swap points:** COPY `hubEyebrow`, `sideL`/`sideR` (two short lines each, ≤ 5 letters per line), `hubCaption` (≤ 36 chars), `caseEyebrow`/`caseTitle`/`caseNumbers[3]`/`caseNames[3]` (showcase cases), `passEyebrow`, `passTitle`/`passAccent` (≤ 7 letters per line), `passLine`, `passMeta`, `stubText`. Art: `CASE_ART` array at the top of the script (left, centre, right image URLs). Logo: replace the `INF` SVG string with your mark. Theme roles: --text (pass body), --primary (stub, accent word), --accent/--pop/--warm (ring and foil).
**Adapting:** put your real logo in the stub and make the hole a letterform's counter for a true "zoom into the O". For 16:9 widen the hub scene (three cases fit with more air) but keep the hole centre/radius consistent with h. Use one loop (5 s) as an intro, cutting on the hub read at ~2.5 s.
