# 08 Materializing Result
**Feeling:** precise, satisfying, calm, premium
**Good for:** revealing a result or status screen step by step (onboarding done, order placed, 3-step summary) without showing a real UI
**Avoid when:** the message is a single word or number; the dot gather needs a layout worth materializing
**Mechanism:** a canvas dot field (24×26 hashed dots, periodic drift) converges with a radial stagger into a compact card rectangle; the HTML card shell crossfades in (blur 10→0) and grows .6→1 (emphasized ease) while dashed ghost regions mark the layout. Each region is revealed in order by a clip-path wash with a bright leading edge (header, then three rows); check badges seat on a spring (k 220, c 15) and the tick draws via pathLength. Reverse: the shell fades, dots reappear at their grid slots and scatter with an accelerating exit. Dot colours come from --accent / --primary-hi / --text, read on the first frame (and again via window.onTheme).
**Timing:** DUR 6 s; gather 0.05–1.05, grow 0.8–1.55, header wash 1.3, rows 1.85 / 2.2 / 2.55 (420 ms each), readable hold ~2 s with 2.5% push and a glare pass, dissolve 4.75–5.85. POSTER 3.9.
**Swap points:** COPY `eyebrow` (line above, ≤ 32 chars), `label` (header tag), `headline` (≤ 6 letters), `k1`–`k3` (row kickers), `s1` (1 word), `s2`/`s3` (≤ 32 chars, two lines max), `caseEyebrow`/`caseTitle`/`caseNumber` (mini showcase case), `footer`. Art: add `style="--art:url(...)"` to the `.art` inside `#mini`. Theme roles: --primary/--primary-hi (header band, dots), --accent (row numbers, wash edge, dots), --bg2/--bg3 (card body).
**Adapting:** add a 4th row by copying a `.reg.row` + `.ghost`, offsetting `top` by 196 px and appending to `regs` with the next start time (+0.35 s). For 16:9 put the card on the right half and keep the dot grid's aspect matched to the card (GX/GY). In a longer video, cut out at ~4.7 s (before the dissolve) and use the dissolve only as a closing beat.
